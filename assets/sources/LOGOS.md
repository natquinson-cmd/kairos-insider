# Logos des sources de données

La landing identifie les organismes dont les déclarations publiques sont utilisées par Kairos. Les liens pointent vers leurs sites officiels ; cette présentation ne revendique aucun partenariat ni agrément.

- `sec.png` : sceau SEC déjà présent dans le dépôt, conservé sans retouche.
- `amf-official.svg` : logo compact téléchargé depuis l’en-tête du site AMF le 18 septembre 2026. Source : https://www.amf-france.org/sites/institutionnel/files/logo/AMF_petit_logo_site.svg
- `bafin-official.png` : logo téléchargé depuis l’image de partage du site BaFin le 18 septembre 2026. Source : https://www.bafin.de/SiteGlobals/Frontend/Images/logo-share.png?__blob=banner

Les fichiers officiels sont conservés sans modification et affichés dans leurs couleurs d’origine, sur fond blanc.
